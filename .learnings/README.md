# Knowledge Base

This directory contains transferable learnings extracted by BLD's knowledge-curator agent.

See [INDEX.md](INDEX.md) for the full categorized index.

## Structure
- `patterns/` — What works: proven approaches and best practices
- `pitfalls/` — What to avoid: common mistakes and gotchas
- `decisions/` — Why we chose: architecture and technology rationale
- `process/` — How we work: workflow and coordination learnings
- `debugging/` — How to fix: error patterns and diagnostic techniques
